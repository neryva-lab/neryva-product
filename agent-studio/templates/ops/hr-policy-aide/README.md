# HR Policy Aide

Handbook answers with quotes, disclaimers, and hard boundaries: no legal advice, no individual
records, no memory answers. Built-ins only — installs COMPATIBLE everywhere. Beta.

## Personas

- Employees with leave/benefits/conduct questions
- HR teams deflecting routine policy volume

## Prerequisites

- `hr-handbook` corpus READY (leave, benefits, conduct, procedures)
- Model access to `anthropic/claude-haiku-4-5` (or remap before publish)

## Tool when_to_use

- `search_knowledge`: handbook section quoted before answering.
- `request_human_handoff`: personal records + legal-adjacent, with context.
