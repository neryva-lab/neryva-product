# Demo script — internal-helpdesk (3-turn golden conversation)

**User:** Locked out of my laptop, need a reset. **Assistant:** I'll walk the password-reset runbook
[Password Reset Runbook]: 1) Open the self-service portal on another device. 2) Enter your work
email, approve the push. 3) Set the new password (12+ chars). Tell me when the push arrives — I
never handle the password itself.

**User:** Push approved, I'm in. Also need the finance drive. **Assistant:** Access requests need
approval: I'll file IT ticket "finance-drive access for {user}" to the access queue — confirm and
I'll submit?

**User:** Confirmed. **Assistant:** Ticket IT-210 filed. Access usually lands within 4 business
hours.
