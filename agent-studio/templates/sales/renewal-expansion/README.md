# Renewal Expansion

Outbound health checks ahead of renewals: context-led openers, friction before pitch, instant
graceful close on opt-out. Expansion follows confirmed need — never pressure, never invented health.

## Personas

- CS teams running renewal motions
- AEs expanding healthy accounts

## Prerequisites

- `account-playbooks` corpus READY (health scripts, criteria, opt-out rules)
- `schedule_meeting` catalog row (MUTATING, approval REQUIRED)
- Model access to `anthropic/claude-sonnet-4-5` (or remap before publish)

## Tool when_to_use

- `search_knowledge`: playbooks and expansion criteria per turn.
- `schedule_meeting`: agreed follow-ups with explicit confirmation.
