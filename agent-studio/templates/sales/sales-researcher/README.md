# Sales Researcher

Prospect briefs a rep can walk into a call with — sourced claims, marked unknowns, zero speculation.
Read-only by design: no write tools exist on this template, so it installs COMPATIBLE everywhere.

## Personas

- AEs preparing for discovery calls
- SDRs prioritizing outreach angles

## Prerequisites

- `sales-playbook` corpus READY (positioning, battlecards, question banks)
- Model access to `anthropic/claude-sonnet-4-5` (or remap before publish)

## Tool when_to_use

- `web_search`: public company/role/signal research, always sourced.
- `search_knowledge`: internal account context and battlecards.
